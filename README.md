**Udemy Clone - HTML Prototype**
**Overview**
This project is a front-end prototype of a Udemy-inspired learning website built using HTML and CSS. The goal of this prototype is to replicate the core user interface and browsing experience of a learning platform.

**Features**
Responsive design
Navigation bar with search functionality
Hero section
Recommended courses section
Recommended topics section
Most popular cards
Footer
Mobile-friendly layout

Technologies Used
HTML5
CSS3
Font Awesome (optional)
Google Fonts (optional)
